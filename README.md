# Control de Finanzas

App web para organizar tu dinero en sobres. Funciona sin internet y se instala en iPhone y Android.

**Abrir:** https://ekammil.github.io/control-finanzas/

- iPhone: ábrela en Safari → Compartir → *Agregar a pantalla de inicio*.
- Android: ábrela en Chrome → menú ⋮ → *Instalar app*.

Tus datos se guardan solo en tu teléfono. El respaldo en Google Sheets es opcional (Ajustes → Respaldo en Google Sheets, usa `google-sync.gs`).
